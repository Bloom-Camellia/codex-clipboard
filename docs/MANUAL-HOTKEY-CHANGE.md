# 2026-10-05 手动截图转换变更

用户发现自动转换影响普通图片粘贴，要求用 Ctrl+Q 区分两种操作。

当前行为：

- Win+Shift+S 后不按转换快捷键：剪贴板保持图片，不自动保存，不清理历史。
- 按 Ctrl+Q：保存当前图片为 PNG，成功后写入绝对路径文本，再用 Ctrl+V 粘贴。
- 下一张截图仍默认保持图片；转换快捷键按张生效。
- 自动随 codex 启动、单后台多会话、保留最新30张、保存失败保护和剪贴板版本保护继续生效。
- 退出最后一个 CLI 后释放全局热键。
- 配置默认 Ctrl+Q；隔离测试使用 Ctrl+Alt+Q，实际安装验收验证 Ctrl+Q。
- 修复自定义 profile 卸载误清理实际用户后台会话的问题。

本文件的触发方式取代早期设计中的自动剪贴板图片转换方式。
